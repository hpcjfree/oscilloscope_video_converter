# 黑白视频 → 模拟示波器 XY 音频转换器

这个程序把只有黑、白两种颜色的视频转换为 16-bit 立体声 WAV：

- 左声道：示波器 X 输入
- 右声道：示波器 Y 输入
- 白色区域：提取边界轮廓并按路径扫描
- 黑色区域：作为背景忽略

程序提供桌面图形界面和命令行两种用法。

## 1. 工作原理

程序逐帧读取视频，进行二值化和轮廓提取，把轮廓变成一连串 `(x, y)` 坐标，然后按视频帧率把坐标分配到音频采样点中。最终将 X 写入 WAV 左声道，将 Y 写入右声道。

注意：普通立体声音频只有 X/Y 两路，没有示波器 Z 轴或消隐信号。因此，当一帧中有多个互不相连的轮廓时，电子束从一个轮廓跳到另一个轮廓的过程中可能画出连接线。程序使用最近邻排序尽量缩短连接线，但不能从原理上完全消除。要彻底消隐，需要第三路 Z 轴/亮度控制或专用矢量显示硬件。

## 2. 安装

需要 Python 3.10 或更高版本。

在本目录打开终端：

```bash
python -m venv .venv
```

Windows：

```bat
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux：

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## 3. 启动图形界面

```bash
python oscilloscope_video_converter.py
```

Windows 也可以双击 `run_gui.bat`，但需要先安装 Python。

推荐初始参数：

- 采样率：192000 Hz
- 处理分辨率：640 × 480
- 二值化阈值：127
- 轮廓简化：0.12%
- 输出幅度：0.85
- 每帧重复扫描：2
- 平滑系数：0

如果音频接口只支持 96 kHz，就选择 96000。采样率越高，曲线通常越细腻。

## 4. 命令行用法

```bash
python oscilloscope_video_converter.py input.mp4 output.wav
```

示例：

```bash
python oscilloscope_video_converter.py input.mp4 output.wav \
  --sample-rate 192000 \
  --width 640 --height 480 \
  --threshold 127 \
  --traces 2 \
  --amplitude 0.85
```

查看全部选项：

```bash
python oscilloscope_video_converter.py --help
```

## 5. 示波器连接

1. 将示波器切换到 XY 模式。
2. 音频接口左声道接 X 输入，右声道接 Y 输入，共地。
3. 从很低的音量开始播放 WAV，再慢慢增加。
4. 将声卡/音频接口设置为 WAV 的原始采样率，关闭均衡器、空间音效、响度补偿和系统“音效增强”。
5. 优先使用线路输出或独立音频接口，不要通过扬声器功放输出。
6. 示波器输入建议先使用较高量程或较低灵敏度，确认电压安全后再调整。

很多消费级声卡输出是交流耦合的，会去除直流分量，因此画面可能自动居中或出现低频形变。这是硬件特性，不是 WAV 文件损坏。

## 6. 参数说明

- **采样率**：单位 Hz。推荐 96 kHz 或 192 kHz。
- **处理分辨率**：仅影响轮廓提取精度，不改变视频时长。
- **二值化阈值**：灰度高于阈值视为白色主体。
- **输入反相**：适用于黑色主体、白色背景。
- **最小轮廓周长**：过滤小噪点。
- **轮廓简化**：数值越高，点越少、画面越简单；过高会损失细节。
- **输出幅度**：WAV 满刻度比例。建议不超过 0.9。
- **每帧重复扫描**：提高刷新感，但每次扫描可用采样点减少。
- **平滑系数**：抑制尖锐跳变，但会让拐角变圆。默认关闭。
- **交换/反转轴**：用于修正旋转或镜像。
- **边缘留白**：防止波形贴近满量程边缘。

## 8. 输入视频建议

- 主体尽量使用纯白，背景使用纯黑。
- 线条不要太细，避免压缩编码后断裂。
- 尽量减少同时存在的互不相连图形，可明显减少跳线。
- 使用较低帧率并不一定更差，因为每帧可获得更多音频采样点；24、25、30 fps 都可正常使用。
- H.264 MP4 通常兼容性较好；若 OpenCV 无法读取某种编码，可先用 FFmpeg 转为常见 MP4。
